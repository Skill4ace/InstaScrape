# Privacy Policy for InstaScrape Follower Diff

InstaScrape Follower Diff is a Chrome extension that analyzes the Followers and Following lists for the currently open Instagram profile tab and shows which accounts are not following back.

## Data the extension handles

- Website content from the active `instagram.com` tab, specifically follower and following usernames and related visible profile data needed to perform the comparison.
- Extension state and results stored locally in the browser so the side panel can display progress, diagnostics, and results.

## How data is used

- To compare Followers and Following for the current Instagram profile.
- To display Followers, Following, and Not Following Back results in the extension side panel.

## How data is stored

- Analysis state and results are stored locally in Chrome using extension storage.
- Data is processed locally in the user's browser.

## How data is shared

- The extension does not sell user data.
- The extension does not transfer user data to third parties.
- The extension does not use user data for advertising, profiling, creditworthiness, or lending purposes.

## User control

- The extension only runs when the user starts an analysis.
- Users can clear stored analysis results from the extension interface.
